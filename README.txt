THE HOME PLATE — VERCEL DEPLOYMENT

This is a static website. The home page is index.html.

To deploy: Extract this ZIP, then use Vercel CLI in this folder:
  npx vercel login
  npx vercel --prod

Or upload the extracted folder to a GitHub repository and import that repository in Vercel at https://vercel.com/new .
Framework Preset: Other; Build Command: blank; Output Directory: blank.

No WhatsApp ordering or checkout is included.
